Content (conteudo)

Define a largura da caixa (salvo elementos de bloco)

Padding (preenchimento)

Separa o conteúdo das bordas da caixa. é margem interna

Border (borda)

Define bordas para a caixa

Margin (margem)

define a distância entre uma caixa e outra

Widht (largura)

A largura total caixa, por padrão é o somatório do conteúdo + padding (left/right) + border (left/right)

Height

A altura total da caixa, por padrão é o somatorio dp conteúdo + padding (top/bottom) + border (top/bottom)
